# LLM Wiki Maintenance

Scope: everything under `docs/llm-wiki/`.

When editing this wiki:

- Keep `wiki/index.md` as the shortest reliable entry point for LLMs.
- Prefer concise, evidence-backed summaries over copied source text.
- Register external URLs, repo files, screenshots, and generated artifacts in `sources.md`.
- Put large or raw source material under `raw/`; do not make raw files the default reading path.
- Mark uncertain claims as `待验证`.
- Use absolute or repo-relative file paths for evidence.
- Update `notes/changelog.md` for meaningful structural or factual changes.
- Do not store secrets, credentials, tokens, private customer data, or production dumps.
- Do not copy long copyrighted passages into wiki pages; summarize and link to sources instead.
