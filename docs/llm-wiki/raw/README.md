# Raw Materials

Use this directory for original or near-original source material that should not be loaded by default.

Examples:

- copied meeting notes
- exported API payload samples
- screenshots with annotations
- long upstream references
- investigation logs

Rules:

- Prefer one file per source.
- Name files with a date and topic, for example `2026-05-09-iep-plan-flow.md`.
- Remove secrets, credentials, tokens, private customer identifiers, and production dumps.
- Summarize important findings into `../wiki/` and register the source in `../sources.md`.
