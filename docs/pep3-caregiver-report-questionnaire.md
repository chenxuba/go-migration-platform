# PEP-3 儿童照顾者报告问卷整理

来源：`/Users/chenrui/Desktop/教学教研/教研/pep3/照顾报告彩.pdf`

## 结论

儿童照顾者报告是由家长或主要照顾者根据儿童近期日常表现填写的自评/他评问卷，不是测试员现场操作题。软件中应支持两种入口：

- 家长端填写：老师发链接或二维码，家长在手机端完成问卷。
- 测试员代填：测试员根据纸表或访谈结果在后台录入。

问卷包含五部分，其中只有三部分进入 PEP-3 照顾者报告原始分：

| 部分 | 代码 | 是否计分 | 计分说明 | 满分 |
|---|---|---:|---|---:|
| 儿童现时发展程度 | current_development | 否 | 填写估计年龄，仅作背景信息 | -- |
| 诊断类别及程度 | diagnosis | 否 | 诊断矩阵，仅作背景信息 | -- |
| 问题行为 | PB | 是 | 第1-10题：没有出现=2，轻微/中度=1，严重=0；第11题文字备注不计分 | 20 |
| 个人自理 | PSC | 是 | 第1-13题：第一项=2，第二项=1，第三项=0；第14题文字备注不计分 | 26 |
| 适应行为 | AB | 是 | 第1-15题：第一项=2，第二项=1，第三项=0；第16题文字备注不计分 | 30 |

## 一、儿童现时发展程度

填写方式：数字输入，单位为“岁”。不计分。

| 题号 | 题目 |
|---:|---|
| 1 | 与一般同龄儿童比较，儿童的沟通表现（例如：模仿声音、牙牙学语、跟从指令、与人说话及明白他人说话内容）约为多少岁 |
| 2 | 与一般同龄儿童比较，儿童的大小肌肉能力（例如：使用肌肉来活动及使用手部操控物件）约为多少岁 |
| 3 | 与一般同龄儿童比较，儿童的社交能力（例如：享受拥抱及谈话、与人交往、合作地玩耍、交朋友及跟随游戏规则）约为多少岁 |
| 4 | 与一般同龄儿童比较，儿童的自理能力（例如：进食/饮、穿衣、洗澡和如厕）约为多少岁 |
| 5 | 与一般同龄儿童比较，儿童的思考能力（例如：完成砌图、找寻隐藏物件及解决问题）约为多少岁 |
| 6 | 与一般同龄儿童比较，儿童的整体能力（所有技巧）约为多少岁 |

## 二、诊断类别及程度

填写方式：矩阵选择。每行包含“诊断类别：是/不是/不知道”和“对儿童发展的影响程度：轻微/中度/严重”。不计分。

诊断类别：语言障碍、自闭症、情绪困扰、学习障碍、智力迟缓、专注力不足/过度活跃症、亚氏保加症、精神分裂症、广泛发展障碍、蕾特氏症、其他。

## 三、问题行为（PB）

填写方式：单选。第1-10题计分；第11题为文本备注。

通用选项：

| 选项 | 分值 |
|---|---:|
| 此问题没有出现 | 2 |
| 此问题有出现，程度是轻微/中度 | 1 |
| 此问题有出现，程度是严重 | 0 |

| 题号 | 题目 | 类型 |
|---:|---|---|
| 1 | 缺乏或不适当的眼神接触、缺乏面部表情以及缺乏沟通上的身体语言 | 单选 |
| 2 | 语言发展迟缓或完全不说话 | 单选 |
| 3 | 经常投入在一个或多个重复的兴趣或活动，兴趣异常强烈，或者兴趣过分狭窄 | 单选 |
| 4 | 不能如其他同龄孩子一样发展友谊 | 单选 |
| 5 | 有适当的语言，但不能主动与人开展对话或与人保持对话 | 单选 |
| 6 | 坚持某个或某些重复而没有实际功能的常规或仪式 | 单选 |
| 7 | 不会自发地与人分享开心的活动、有趣的事物或成功的事情 | 单选 |
| 8 | 使用重复或古怪的语言 | 单选 |
| 9 | 出现重复的身体活动，例如拍打或摆动手/手指、扭曲身体或作出复杂的身体动作 | 单选 |
| 10 | 与人沟通时，不表达自己感受或不回应别人所表达的情绪 | 单选 |
| 11 | 其他问题行为（请列出） | 多行文本 |

|---:|---|---|---|---|

## 五、适应行为（AB）

|---:|---|---|---|---|

## 前端交互建议

建议不要把照顾者报告做成一个长表格，而是做成“分步骤问卷”：

1. 第一步：基础信息。显示儿童姓名、性别、报告日期、家长姓名，可由评估记录自动带出。
2. 第二步：现时发展程度。6个数字输入，单位固定显示“岁”，允许保留一位小数。
3. 第三步：诊断类别及程度。矩阵表格，移动端可改成每个诊断类别一张小卡，先选“是/不是/不知道”，如果选“是”再显示“轻微/中度/严重”。
4. 第四步：问题行为。每题单选，选项固定为“没有出现/轻微或中度/严重”，自动计算 `PB` 原始分。
5. 第五步：个人自理。每题单选，选项按能力水平从高到低排列，自动计算 `PSC` 原始分。
6. 第六步：适应行为。每题单选，选项按适应水平从高到低排列，自动计算 `AB` 原始分。
7. 提交页：展示 `PB/PSC/AB` 三个原始分、漏填题目、备注。测试员确认后写入 PEP-3 评估草稿或正式记录的 `rawScoreList`。

接口上，后端 `form-template` 已适合返回 `caregiverReport` 结构；前端只需要按 `section.inputType` 渲染即可。保存时建议同时保存逐题答案和自动汇总出的 `rawScoreList`，这样报告能复原家长原始问卷，也能直接接入现有常模换算。
