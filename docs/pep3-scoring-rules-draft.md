# PEP-3 计分与换算规则草稿

来源：`/Users/chenrui/Desktop/教学教研/教研/pep3/PeP3测试员手册 (2).pdf`、`PEP-3常模(2025).pdf`、已整理题库。

## 1. 基础计分

- 所有测试项目按 `0/1/2` 计分。
- 发展副测验：`2=通过`，`1=部分通过`，`0=未能通过`。
- 行为副测验：`2=恰当`，`1=轻微`，`0=严重`。
- 每题具体评分条件以题库中的 `standard` 字段为准。
- 测试不设统一下限/上限；测试员可按儿童状态弹性调整项目顺序，但评分要遵守每题指导和评分标准。

## 2. 原始分

- 每个分量表的原始分 = 该分量表所有题目得分相加。
- 发展及行为副测验分量表：`CVP`、`EL`、`RL`、`FM`、`GM`、`VMI`、`AE`、`SR`、`CMB`、`CVB`。
- 儿童照顾者报告分量表：`PB`、`PSC`、`AB`。
  - `PB` 问题行为：第1-10题计分；没有问题=2，轻微/中度=1，严重=0；第11题“其他问题行为”为文字备注，不计分；满分20。
  - `PSC` 个人自理：第1-13题计分；第一行=2，第二行=1，第三行=0；第14题“其他自理问题”为文字备注，不计分；满分26。
  - `AB` 适应行为：第1-15题计分；第一行=2，第二行=1，第三行=0；第16题“其他异常表现”为文字备注，不计分；满分30。

## 3. 年龄计算

- 使用评估日期减出生日期得到实足年龄。
- 查常模时不能四舍五入；例如 `3岁11个月28天` 按 `3岁11个月` 使用。
- 软件字段建议保存：`birth_date`、`assessment_date`、`age_years`、`age_months_remainder`、`age_days_remainder`、`total_age_months_for_norm`。

## 4. 常模换算

- 发展年龄：用附表1，把副测验原始分换算成相应发展月龄。
- 百分比级数：用附表2，按儿童实足年龄组和副测验原始分查百分位。
- 标准分数：用附表3，按儿童实足年龄组和副测验原始分查标准分；标准分主要用于计算合成分数，不建议单独解释。
- 合成百分位：先把相关副测验标准分相加，再用附表4.1 换算百分比级数。

## 5. 合成分数

| 合成项目 | 包含分量表 | 计算 |
|---|---|---|
| 沟通 `communication` | `CVP + EL + RL` | 三个标准分相加后查附表4.1 |
| 体能 `motor` | `FM + GM + VMI` | 三个标准分相加后查附表4.1 |
| 适应不良的行为 `maladaptive_behavior` | `AE + SR + CMB + CVB` | 四个标准分相加后查附表4.1 |

- 沟通和体能的发展年龄：分别把所属副测验发展年龄相加后取平均值。
- 儿童照顾者报告的标准分不进入测试员记录册第3部分的合成分数。

## 6. 发展/适应程度

| 百分比级数 | 发展/适应程度 |
|---:|---|
| `>89` | 恰当 |
| `75-89` | 轻微 |
| `25-74` | 中度 |
| `<25` | 严重 |

## 7. 软件落地建议

- 录入层：保存每题得分、无法测/跳过原因、测试员备注。
- 汇总层：按 `domain_code` 自动汇总原始分，并记录每个分量表的满分。
- 换算层：根据 `total_age_months_for_norm` 选择年龄组，再查百分位和标准分。
- 报告层：展示原始分、发展年龄、百分位、发展/适应程度、合成分数，并保留来源表号用于审计。
- 风险控制：常模表 OCR 版只可用于开发联调；上线前必须以人工校对版替换。
