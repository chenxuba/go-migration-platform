# 康复教育机构监管驾驶舱

面向政府监管端的 1920×1080 静态可视化大屏项目，基于机构端业务抽象监管视角，中间辖区地图使用 Three.js 实现 3D 立体地图，覆盖机构运营、学员结构、教学服务、资金课消和风险预警。

## 运行

```bash
cd government-screen
npm install
npm run dev
```

默认开发端口：`6699`

## 构建

```bash
cd government-screen
npm run build
npm run preview
```

预览端口：`6799`

## 页面说明

- 顶部：监管单位、标题、区域筛选、更新时间和核心 KPI。
- 中部：辖区机构分布地图、风险点位、机构 tooltip 和实时动态。
- 左侧：机构活跃度、学员结构、家长绑定与通知触达。
- 右侧：教学排课、点名异常、老师负载、康复记录和家长反馈。
- 底部：资金趋势、欠费预警、续费提醒和审批流监控。

当前为静态页面，数据集中写在 `src/App.vue`，后续可替换为接口返回数据。

> 说明：项目也兼容 pnpm；如果本机 pnpm 镜像源报错，直接使用 npm 即可。

## 技术说明

- 前端：Vue 3 + Vite。
- 地图：`src/components/Map3D.vue` 使用 Three.js 渲染立体辖区、流光线路和机构风险点位。
- 视觉：`src/styles.css` 固定 1920×1080 设计稿比例，并根据浏览器窗口等比缩放。
